# Rise of Legends Remastered — source

Source code of Rise of Legends Remastered, a graphics mod for Rise of Nations: Rise of Legends (Steam version).
Releases are published on Nexus Mods. This repository holds one snapshot per release; no game files are included.

## Layout

| Path | Contents |
|---|---|
| `native/rolhook/` | rolhook, the mod's runtime: a `ddraw.dll` proxy that the game loads from its folder. It forwards every DirectDraw export to the system `ddraw.dll` and hooks Direct3D 9 and engine functions for the mod's features: HD texture override, shadow map size and filtering, SSAO, sharpening and vibrance, UI scaling, animation smoothing, the in-game Mods tab. Logs go to `modkit\logs\sessions`. |
| `tools/` | `modmgr.py` — installer: backs up and patches game files, rebuilds `.big` archives, restores everything on uninstall. `bigtool.py`, `bxml.py`, `entrypatch.py` — game archive and data formats. `release.py` / `release_check.py` — release build and clean install/uninstall test. `autotest.py` — automated test runs. `compare.py`, `promo.py` — before/after images. |
| `modpack/` | The mods: `mod.ini`, rolhook settings (`rolhook.d/*.ini`), patch scripts for game data. `release.ini` lists the mods of the release. |
| `release/` | `Install.bat`, `Uninstall.bat`, player READMEs, mod page texts. |
| `hd/` | Scripts that generated the HD textures (ComfyUI with PBRify, Real-ESRGAN, FLUX.1-dev). |
| `tests/` | Templates for the automated test runs. |

The repository is used from the game folder as `modkit\` (the tools resolve the game as its parent folder).

## Building ddraw.dll

Requirements: Visual Studio 2022 Community with "Desktop development with C++" (the `vcvars32.bat` path is set in `mk.bat`).

1. Run `native\rolhook\mk.bat`.
2. Output (x86, static CRT):
   - `build\native\player\ddraw.dll` — the players' build, the one releases ship. Compiled with `ROLHOOK_PLAYER`:
     without the developer tools (probes, automated test runs, frame capture, call counting, motion and script
     traces, the sprite log, memory dumps; `native/rolhook/player_stubs.cpp`), so it has no input injection, thread
     control or process-memory reads. `tools/release.py` checks its imports before packaging.
   - `build\native\ddraw.dll` — the full build with the developer tools, for development and the automated tests.
   - `smoke.exe`, `shadertest.exe` — offline tests.

## Building the release

Requirements: Python 3.14, the game with the mod set up from this folder (`py -3.14 tools\modmgr.py setup`).

`py -3.14 tools\release.py --no-hd` builds `dist\RoL_Remastered_<version>.zip`; without `--no-hd` it also packs the HD
textures from `mods\hd` (generated by `hd\`). The bundled Python is the official embeddable package from python.org
(binaries unmodified, signed by the Python Software Foundation), trimmed to what the installer imports.
`py -3.14 tools\release_check.py` installs and uninstalls the built release on a copy of the game.
