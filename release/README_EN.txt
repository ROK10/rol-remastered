RISE OF LEGENDS REMASTERED {version}
A graphics modpack for Rise of Nations: Rise of Legends. It changes how the game looks, not how it plays: units,
buildings, rules and balance are as they were. Multiplayer against players without the modpack has not been tested.

WHAT YOU GET
  - HD textures for terrain, buildings, units, trees, effects and the campaign map (separate download, see below)
  - A larger interface with crisp text for high resolutions: the scale follows your screen automatically
    (1440p: 150%, 4K: 200%) or can be set by hand, 125-200%
  - Shadows: 4096/8192 shadow maps, soft shadow edges, sharper shadows when zoomed out
  - Ambient occlusion (soft contact shadows where buildings meet the ground, in corners, under trees)
  - Sharpening (AMD CAS) and colour vibrance; optional gamma-correct lighting on buildings and units
  - 16x anisotropic filtering, smoothed foliage edges, more detailed models in the distance
  - Smooth animation (units and turning parts of buildings move every frame)
  - Farther camera zoom with more zoom steps and an adjustable zoom bounce
  - Borderless fullscreen; persistent battlefield markings; 4 GB of memory for the game
  - A new "Mods" tab in the Options window to adjust all of this, in your game's language
    (English, Deutsch, Français, Italiano, Español, Polski, Čeština, Русский, 日本語, 繁體中文)

REQUIREMENTS
  - Rise of Nations: Rise of Legends, disc version with the official 2.5 patch (legends.exe of 10 April 2007)
  - Windows 10 or 11, a graphics card with Shader Model 3 (any card from the last 15 years)

INSTALLING
  1. Close the game.
  2. Unpack RoL_Remastered_{version}.zip into the game folder (the folder with legends.exe).
  3. Optional, recommended: unpack the HD pack (RoL_Remastered_{version}_HD.zip) into the same folder.
     It only adds files to modkit\mods\hd.
  4. Run Install.bat. It takes a minute or two.
  Install.bat backs up every game file it changes into modkit\backup. Run it again after adding the HD pack later,
  or after switching the game's language, so that the Mods tab follows the new language.

SETTINGS
  In the game: Options (F11) - Mods. Most settings apply at once, even during a match. Those marked with the star
  icon apply after restarting the game. "Defaults" on the Mods tab brings back the modpack's settings.

UNINSTALLING
  Run Uninstall.bat in the game folder. Every original file is put back; then the modkit folder, Install.bat and
  Uninstall.bat can be deleted.

IF SOMETHING GOES WRONG
  - Reinstalling or re-patching the game restores the original legends.exe and archives; run Install.bat again
    afterwards.
  - Some antivirus programs distrust ddraw.dll in a game folder: the modpack works through it (it is how the mod
    hooks into the game). Allow it, or uninstall the modpack.
  - Logs of every game session are in modkit\logs\sessions - please attach the newest folder when you report a problem.
